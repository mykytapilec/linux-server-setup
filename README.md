# Linux Server Setup

A practical Linux server setup project based on the roadmap.sh Linux Server Setup project.

## Project Goals

- Create and configure a non-root user with sudo access.
- Configure SSH key-based authentication.
- Disable SSH password authentication.
- Configure UFW firewall rules.
- Configure automatic security updates.
- Install and configure Fail2Ban.
- Configure the server hostname and timezone.
- Manage services with systemd.
- Inspect and manage system logs.
